# SPACE EX

An interactive, mobile-friendly field guide to the cosmos.

## Explore
- Interactive Solar System overview with selectable planets
- Searchable catalogue of planets, moons, stars and extreme objects
- Cosmic oddities, quick knowledge quiz and space mission gallery
- Scale-of-the-universe explorer

## Stack
A deliberately lightweight static web app: HTML, CSS and vanilla JavaScript. No API keys, database, build step or paid services required.

## Deploy
Connected to Vercel. Every push to the default branch can trigger a production deployment.

Astronomical facts are simplified for accessibility; measurements and discovery counts can change as research advances.
